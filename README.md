# ModbusPilot downloads

Public release files for **ModbusPilot**: read any Modbus device in plain language. It covers Modbus RTU/TCP, RS485 serial and SSH.

* Website: https://modbuspilot.com
* Download page: https://modbuspilot.com/download/
* Latest release: https://github.com/npatil15/ModbusPilot-releases/releases/latest

Files in each release:

| File | What it is |
| --- | --- |
| `ModbusPilot-Setup.exe` | Windows installer (recommended) |
| `ModbusPilot.exe` | Windows portable app |
| `ModbusPilot-Master.exe` | Standalone Modbus Master |
| `ModbusPilot-Slave.exe` | Standalone Modbus Slave simulator |
| `modbuspilot-cli.exe` | Command-line tool and MCP server |

SHA-256 checksums are in each release's notes. This repository holds release files only; the source code is private.
